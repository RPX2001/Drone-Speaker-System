This is my research on making a noise cancelling device for drone. I mainly focus on cancelling out noise from drone propellers. I'm using microphone array as the reference microphones and use loud speaker array as the secondary source. I'm trying to apply FxLMS algorithm for adaptive active noise cancelling and implement this as light weight low power system. Also, I tested my algorithm in MATLAB Simulation and then I'm implmenting that on STM32H743VIT6 microcntroller based platform.
